# Contributing to SandBase Lab

We welcome reproducible experiments, evaluation cases, documentation improvements, and production lessons.

## Where to contribute

- For an existing agent, open an issue or pull request in that project's repository.
- For a new lab or collection-wide guidance, use the [Lab Guide](https://github.com/sandbase-lab/lab-guide/issues).
- You do not need organization membership to contribute.

## New labs

Describe the real task, expected artifact, target user, model/API/sandbox dependencies, and expected costs. Include a minimal reproducible example and known limitations. Follow the [project standard](https://github.com/sandbase-lab/lab-guide/blob/main/docs/project-standard.md).

## Pull requests

Explain the change and how it was verified. Workflow changes should include relevant sample runs or evaluation results; documentation-only changes should be checked for accuracy and links. Do not submit credentials, private customer data, or assets you lack permission to share.

Respect the project license and other contributors. Keep feedback specific and constructive.
